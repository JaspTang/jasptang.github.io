# Portfolio photos

Add JPG images here using these exact filenames. The website will use them automatically.

- `profile.jpg` — your main portrait, ideally a vertical photo.
- `collage-01.jpg` — a detail, project, or world-around-you image.
- `collage-02.jpg` — another supporting collage image.
- `hero-art.jpg` — a wide Canva collage for the top of the page. Export around 2000 × 1200 pixels.

The SVG files in this folder are deliberate visual fallbacks. They remain visible until you add the corresponding JPG.
