# Portfolio photos

Add JPG images here using these exact filenames. The website will use them automatically.

- `about-left.jpg` — a photo to flank the About text on the left.
- `about-right.jpg` — a photo to flank the About text on the right.
- `hero-art.jpg` — a wide Canva collage for the top of the page. Export around 2000 × 1200 pixels.

Use photos of yourself working, equipment, or anything that captures your curiosity. The About photos display as clean rectangles. Until you add them, colorful illustrated placeholders fill the slots.

## Custom font

`fonts/Jaspersfont-Regular.otf` is used for paragraph and supporting copy. Page titles and headings continue to use Nunito.

## Project card previews

Add JPG images here to use them as the right-side previews in the Selected Work cards. Wide images work best; each card crops its image to fill the preview area.

- `vector-compute-engine.jpg` for the Vector Compute Engine.
- `analog-music-light-interface.jpg` for the Analog Music/Light Interface.
- `music-synthesizer.jpg` for the Music Synthesizer.
- `heat-simulation.jpg` for the GPU-interfaced Heat Simulation card and blurred title banner.
- `neutrino-simulation.jpg` for the Neutrino Simulation card and blurred title banner.
- `physics-sandbox.jpg` for the Physics Sandbox.

Use JPG photos for the Heat Simulation and Neutrino cards and their blurred title banners. The site looks for these exact filenames in this folder and shows a placeholder on the cards until each photo is added. The homepage Heat feature and both project pages continue to use their animated GIF previews.

## Neutrino project slides

Add the final presentation PDF as `neutrino-simulation-slides.pdf` in this folder. The Neutrino Simulation project page will automatically show it in an embedded viewer below the project photo, with a link to open the PDF separately. Keep the `.pdf` extension and exact filename so the page can find it.

If a project preview image is missing, the card shows a soft-color placeholder with the expected filename.
